# 📊 Data Visualization Lab

This repository contains Python programs and Google Colab notebooks developed for the **Data Visualization Lab**, focusing on data preprocessing, statistical plotting, and interactive charts using libraries like `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, and `Plotly`. You can click on any `.ipynb` file in this repository and select **Open in Colab** to view and execute the experiments directly in your browser.
